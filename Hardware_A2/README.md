# Hardware_A2 仪表放大器放大倍数及相关特性说明

## 1. 仪表放大器结构

仪表放大器通常由三个运算放大器组成：

1. 前级由两个同相输入运放构成，分别接收差分输入信号 `Vin+` 和 `Vin-`。
2. 两个前级运放的反相端之间通过增益电阻 `Rg` 相连。
3. 后级由一个差分放大器构成，用于对前级两个输出信号作差并进一步放大。

这种结构的核心优点是输入阻抗高、差模信号放大能力强、共模信号抑制能力较好，适合测量幅值很小、容易受干扰的传感器信号。

## 2. 前级放大倍数推导

设输入信号为：

```text
Vin+ = V1
Vin- = V2
```

理想运放满足：

```text
同相端电压 = 反相端电压
输入端电流 = 0
```

因此，上方运放的反相端电压等于 `V1`，下方运放的反相端电压等于 `V2`。

设两个反馈电阻均为 `R`，两个前级运放输出分别为：

```text
Vo1：上方运放输出
Vo2：下方运放输出
```

对上方反相端节点列 KCL：

```text
(V1 - Vo1) / R + (V1 - V2) / Rg = 0
```

整理得：

```text
Vo1 = V1 + (R / Rg)(V1 - V2)
```

对下方反相端节点列 KCL：

```text
(V2 - Vo2) / R + (V2 - V1) / Rg = 0
```

整理得：

```text
Vo2 = V2 + (R / Rg)(V2 - V1)
```

两路输出相减：

```text
Vo1 - Vo2
= [V1 + (R / Rg)(V1 - V2)] - [V2 + (R / Rg)(V2 - V1)]
= (V1 - V2) + (R / Rg)(V1 - V2) + (R / Rg)(V1 - V2)
= (1 + 2R / Rg)(V1 - V2)
```

所以前级差模放大倍数为：

```text
A1 = 1 + 2R / Rg
```

## 3. 后级差分放大倍数

后级差分放大器由四个电阻组成。若电阻匹配满足：

```text
R5 = R4
R7 = R6
```

则后级差分放大倍数为：

```text
A2 = R7 / R5
```

后级输出为：

```text
Vout = (R7 / R5)(Vo2 - Vo1)
```

若只讨论幅值大小，则总放大倍数为：

```text
Av = (1 + 2R / Rg)(R7 / R5)
```

其中：

```text
R：前级两个反馈电阻
Rg：前级两个反相端之间的增益电阻
R5、R7：后级差分放大器的输入电阻和反馈电阻
```

## 4. 本次仿真参数计算

本次 Multisim 仿真中采用的主要参数为：

```text
R = 10kΩ
Rg = 20kΩ
R5 = 10kΩ
R7 = 10kΩ
```

前级放大倍数：

```text
A1 = 1 + 2R / Rg
   = 1 + 2 * 10kΩ / 20kΩ
   = 2
```

后级差分放大倍数：

```text
A2 = R7 / R5
   = 10kΩ / 10kΩ
   = 1
```

总放大倍数：

```text
Av = A1 * A2
   = 2 * 1
   = 2
```

因此，当输入方波幅值约为 `100mV` 时，输出方波幅值理论上约为：

```text
Vout ≈ 100mV * 2 = 200mV
```

实际仿真中示波器显示输出约为 `202mV`，与理论值基本一致，误差可能来自器件模型、读数精度和仿真设置。

## 5. 仪表放大器的应用及结构原因

### 5.1 传感器微弱信号放大

仪表放大器常用于热电偶、应变片、电桥、压力传感器、称重传感器等场景。这类传感器输出信号通常只有毫伏级，直接采集容易被噪声淹没。

仪表放大器前级采用同相输入结构，输入阻抗很高，不会明显影响传感器本身的输出；同时可以通过 `Rg` 调节差模增益，把微弱差分信号放大到后续 ADC 或单片机更容易采集的范围。

### 5.2 抑制共模干扰

在实际测量中，两根输入线可能同时受到电源噪声、电磁干扰或地电位差影响，这些干扰通常表现为共模信号，即同时加在 `Vin+` 和 `Vin-` 上。

仪表放大器的后级差分放大器只放大两个输入之间的差值，对两个输入端共同出现的电压变化有抑制作用。因此，它比普通单端放大器更适合远距离传感器测量和工业现场信号采集。

### 5.3 增益调节方便

三运放仪表放大器的前级增益公式为：

```text
A1 = 1 + 2R / Rg
```

可以看出，只需要改变 `Rg`，就能改变主要放大倍数，而不需要同时修改多个电阻。这种结构便于调试，也便于设计可变增益测量电路。

### 5.4 常见应用场景

```text
电子秤：放大应变片电桥输出的毫伏级差分信号
心电采集：放大人体电极上的微弱生物电信号
工业采集：放大远距离传感器差分信号并抑制干扰
温度测量：放大热电偶输出的小电压信号
```

## 6. 总结

仪表放大器通过两个同相输入运放提供高输入阻抗和可调差模增益，再通过后级差分放大器完成差分输出和共模抑制。本次仿真参数下理论放大倍数约为 `2`，输入 `100mV` 方波时输出约为 `200mV` 方波，仿真结果与理论计算基本一致。

## 7. 学习过程

本题是在完成 `Hardware_A1` 的 Multisim 仿真后，对仪表放大器的公式和应用进行整理。学习过程主要分为三步：

1. 先根据仿真电路确认三运放仪表放大器的结构，区分前级两个同相放大器和后级差分放大器。
2. 再利用理想运放的两个基本条件进行推导，即输入端电流近似为 0、负反馈状态下同相端和反相端电压近似相等。
3. 最后结合仿真参数 `R = 10kΩ`、`Rg = 20kΩ`、后级电阻比为 1，计算理论增益并与示波器读数进行对比。

通过对比发现，输入约为 `100mV` 时输出约为 `202mV`，与理论增益 `2` 基本一致，说明公式推导与仿真结果能够对应。

## 8. 关键知识点总结

```text
仪表放大器总增益 = 前级增益 * 后级差分放大增益
前级增益 A1 = 1 + 2R / Rg
后级增益 A2 = R7 / R5
总增益 Av = (1 + 2R / Rg)(R7 / R5)
```

前级两个运放采用同相输入，因此输入阻抗高，适合接传感器等弱信号源。后级差分放大器只放大两路信号之间的差值，因此可以抑制共模干扰。

## 9. 踩坑记录

### 9.1 公式符号容易混淆

推导时需要先规定 `Vin+ = V1`、`Vin- = V2`，否则在写 `Vo1 - Vo2` 或 `Vo2 - Vo1` 时容易出现正负号混乱。实际使用时，输出极性取决于后级差分放大器的接线方向，但幅值放大倍数不受符号影响。

### 9.2 不能只看参考图参数

参考图中的直流输入可以帮助理解差分放大，但 A1 题要求输出为方波，因此仿真时应使用方波源。A2 推导时则应重点关注电阻关系和放大倍数公式。

### 9.3 后级电阻需要成比例匹配

后级差分放大器若要正确抑制共模信号，电阻比例需要匹配：

```text
R7 / R5 = R6 / R4
```

如果比例不匹配，共模抑制能力会下降，输出结果也可能偏离理论值。
