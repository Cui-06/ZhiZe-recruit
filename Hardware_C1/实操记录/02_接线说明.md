# Hardware_C1 接线图

## 一、模块接线总表

| 模块 | 模块端口 / 信号 | 单片机 / 开发板引脚 | 说明 |
| --- | --- | --- | --- |
| DRV8833 电机驱动 | `AIN1` | `P1.0` | 电机控制输入 1 |
| DRV8833 电机驱动 | `AIN2` | `P1.1` | 电机控制输入 2 |
| DRV8833 电机驱动 | `AOUT1` | 电机一端 | 接两线直流电机任意一根线 |
| DRV8833 电机驱动 | `AOUT2` | 电机另一端 | 接两线直流电机另一根线 |
| DRV8833 电机驱动 | `VM` | `5V` | 按驱动板和电机额定电压供电 |
| DRV8833 电机驱动 | `GND` |  `GND` | 单片机、驱动板、电机电源必须共地 |
| 蜂鸣器 | `Buzzer` | `P2.5` | 高速档时发出“滴露滴露”提示音 |
| LED | `LED` | `P2.0` | 初始化时熄灭 |
| 动态数码管 | 段选 `A~DP` | `P0` | `SMG_A_DP_PORT` 定义为 `P0` |
| 动态数码管 | 位选 `LSA` | `P2.2` | 74HC138 位选控制 |
| 动态数码管 | 位选 `LSB` | `P2.3` | 74HC138 位选控制 |
| 动态数码管 | 位选 `LSC` | `P2.4` | 74HC138 位选控制 |
| 独立按键 | `KEY1` | `P3.1` | 控制电机停止、低速、中速、高速循环切换 |
| 独立按键 | `KEY2` | `P3.0` | 设置电机正转 |
| 独立按键 | `KEY3` | `P3.2` | 设置电机反转 |
| 独立按键 | `KEY4` | `P3.3` | 当前程序未使用 |

## 二、电机驱动接线

| DRV8833 | 连接位置 | 作用 |
| --- | --- | --- |
| `AIN1` | `P1.0` | 电机方向 / PWM 控制信号 |
| `AIN2` | `P1.1` | 电机方向 / PWM 控制信号 |
| `AOUT1` | 电机一端 | 电机输出端 |
| `AOUT2` | 电机另一端 | 电机输出端 |
| `VM` | `5V` | 给电机供电 |
| `GND` | `GND`  | 共地 |

## 三、按键功能表

| 按键 | 引脚 | 功能 |
| --- | --- | --- |
| `KEY1` | `P3.1` | 每按一次切换一个速度档位：停止 -> 低速 -> 中速 -> 高速 -> 停止 |
| `KEY2` | `P3.0` | 设置电机正转 |
| `KEY3` | `P3.2` | 设置电机反转 |
| `KEY4` | `P3.3` | 当前未使用 |

## 四、运行状态对应关系

| 状态 | 电机 | 蜂鸣器 | 
| --- | --- | --- | 
| 上电初始 | 停止 | 不发声 | 
| 低速档 | 低速旋转 | 不发声 |
| 中速档 | 中速旋转 | 不发声 | 
| 高速档 | 高速旋转 | 发出双频提示音 | 
| 再按 `KEY1` | 停止 | 不发声 |
