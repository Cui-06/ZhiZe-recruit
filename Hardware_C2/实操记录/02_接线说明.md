# Hardware_C2 接线说明

## 一、模块接线总表

| 模块 | 模块端口 / 信号 | 单片机 / 开发板引脚 | 说明 |
| --- | --- | --- | --- |
| DRV8833 电机驱动 | `AIN1` | `P1.0` | 电机控制输入 1，用于 PWM 和方向控制 |
| DRV8833 电机驱动 | `AIN2` | `P1.1` | 电机控制输入 2，用于 PWM 和方向控制 |
| DRV8833 电机驱动 | `AOUT1` | 电机一端 | 接两线直流电机任意一根线 |
| DRV8833 电机驱动 | `AOUT2` | 电机另一端 | 接两线直流电机另一根线 |
| DRV8833 电机驱动 | `VM` | `5V` 或电机外部电源正极 | 按电机和驱动板要求供电 |
| DRV8833 电机驱动 | `GND` | `GND` | 单片机、驱动板、电机电源必须共地 |
| OLED | `SCL` | `P1.2` | 软件 IIC 时钟线 |
| OLED | `SDA` | `P1.3` | 软件 IIC 数据线 |
| OLED | `VCC` | `3.3V` 或 `5V` | 按 OLED 模块标注供电 |
| OLED | `GND` | `GND` | 与单片机共地 |
| 蜂鸣器 | `Buzzer` | `P2.5` | 高速档时发出“滴露滴露”提示音 |
| LED | `LED` | `P2.0` | 初始化时熄灭 |
| 动态数码管 | 段选 `A~DP` | `P0` | `SMG_A_DP_PORT` 定义为 `P0` |
| 动态数码管 | 位选 `LSA` | `P2.2` | 74HC138 位选控制 |
| 动态数码管 | 位选 `LSB` | `P2.3` | 74HC138 位选控制 |
| 动态数码管 | 位选 `LSC` | `P2.4` | 74HC138 位选控制 |
| 独立按键 | `KEY1` | `P3.1` | 控制电机停止、低速、中速、高速循环切换 |
| 独立按键 | `KEY2` | `P3.0` | 设置电机正转 |
| 独立按键 | `KEY3` | `P3.2` | 设置电机反转 |
| 独立按键 | `KEY4` | `P3.3` | 当前程序未使用 |

## 二、OLED 接线说明

| OLED 模块 | 开发板引脚 | 作用 |
| --- | --- | --- |
| `SCL` | `P1.2` | IIC 时钟线 |
| `SDA` | `P1.3` | IIC 数据线 |
| `VCC` | `3.3V` 或 `5V` | OLED 电源 |
| `GND` | `GND` | 共地 |

本工程中 OLED 使用软件 IIC，源码中对应定义为：

```c
sbit OLED_SCL = P1^2;
sbit OLED_SDA = P1^3;
```

## 三、电机驱动接线说明

| DRV8833 | 连接位置 | 作用 |
| --- | --- | --- |
| `AIN1` | `P1.0` | 电机方向 / PWM 控制信号 |
| `AIN2` | `P1.1` | 电机方向 / PWM 控制信号 |
| `AOUT1` | 电机一端 | 电机输出端 |
| `AOUT2` | 电机另一端 | 电机输出端 |
| `VM` | `5V` 或电机外部电源正极 | 给电机供电 |
| `GND` | `GND` | 单片机、驱动板、电机电源共地 |

## 四、按键功能表

| 按键 | 引脚 | 功能 |
| --- | --- | --- |
| `KEY1` | `P3.1` | 每按一次切换一个速度档位：停止 -> 低速 -> 中速 -> 高速 -> 停止 |
| `KEY2` | `P3.0` | 设置电机正转 |
| `KEY3` | `P3.2` | 设置电机反转 |
| `KEY4` | `P3.3` | 当前未使用 |

## 五、运行状态对应关系

| 状态 | 电机 | 蜂鸣器 | OLED |
| --- | --- | --- | --- |
| 上电初始 | 停止 | 不发声 | 熄灭 |
| 低速档 | 低速旋转 | 不发声 | 熄灭 |
| 中速档 | 中速旋转 | 不发声 | 熄灭 |
| 高速档 | 高速旋转 | 发出双频提示音 | 从右向左滚动显示“急救请避让” |
| 再按 `KEY1` | 停止 | 不发声 | 熄灭 |
