# Shape 图形类体系设计学习文档

## 一、题目理解

本题要求使用 C++ 建立一个图形类体系：以抽象类 `Shape` 作为基类，派生出 `Circle`、`Rectangle` 和 `Triangle`，并分别计算每种图形的面积和周长。同时，需要通过基类指针或引用调用虚函数，展示运行时动态绑定。

本题的重点不是把三个公式写在一起，而是把“所有图形共有的行为”和“每种图形自己的数据、计算方式”分开：

- `Shape` 只规定图形必须提供的接口；
- 派生类保存自己的尺寸，并实现面积、周长计算；
- 调用方只面向 `Shape` 编程，不需要知道具体派生类型。

## 二、学习过程

### 1. 识别公共行为

圆形、矩形和三角形虽然数据不同，但都有名称、面积和周长。因此在基类中声明：

```cpp
virtual const char* name() const = 0;
virtual double area() const = 0;
virtual double perimeter() const = 0;
```

函数末尾的 `= 0` 表示纯虚函数。含有纯虚函数的 `Shape` 是抽象类，不能直接创建对象，只能作为接口被继承。

### 2. 设计派生类

- `Circle` 保存半径 `radius_`；
- `Rectangle` 保存长 `length_` 和宽 `width_`；
- `Triangle` 保存三条边 `sideA_`、`sideB_`、`sideC_`。

这些数据都设为 `private`，由构造函数检查并初始化，外部不能直接修改，从而保证对象状态有效。

### 3. 实现几何公式

| 图形 | 面积 | 周长 |
| --- | --- | --- |
| 圆形 | `πr²` | `2πr` |
| 矩形 | `length × width` | `2 × (length + width)` |
| 三角形 | 海伦公式 `√(s(s-a)(s-b)(s-c))` | `a + b + c` |

三角形中 `s = (a + b + c) / 2`，即半周长。使用海伦公式时，必须先验证三条边能够组成三角形。

### 4. 展示动态绑定

在 `main` 中把不同派生类对象的地址放入基类指针数组：

```cpp
Shape* shapes[] = {&circle, &rectangle, &triangle};

for (const Shape* shape : shapes) {
    std::cout << shape->area();
    std::cout << shape->perimeter();
}
```

虽然循环变量的静态类型是 `Shape*`，但 `shape->area()` 的实际执行版本由指针指向的对象决定：指向 `Circle` 就调用 `Circle::area()`，指向 `Rectangle` 就调用 `Rectangle::area()`。这就是动态绑定或运行时多态。

## 三、关键知识点总结

### 1. 抽象类和纯虚函数

抽象类用于表达一组对象共有的规范，而不是表示一个可以直接创建的具体对象。纯虚函数只在基类中声明接口，具体实现交给派生类完成。

### 2. 继承与 `override`

```cpp
class Circle : public Shape { ... };
```

`public` 继承表示 `Circle` 是一种 `Shape`。派生类使用 `override` 明确表示重写基类虚函数。如果函数签名不一致，编译器会及时报错，避免误写成普通的新函数。

### 3. 虚析构函数

基类声明：

```cpp
virtual ~Shape() = default;
```

当以后使用 `Shape*` 指向动态创建的派生对象并通过基类指针删除时，虚析构函数能够保证正确调用派生类析构函数。本题中的对象由 `main` 自动管理，但抽象基类仍应保留这一安全设计。

### 4. 多态接口

调用方只依赖 `Shape` 的 `name()`、`area()` 和 `perimeter()` 接口，不需要写出“如果是圆形”“如果是矩形”这样的类型判断。这降低了代码耦合，后续增加 `Square` 或 `Ellipse` 时，只需新增派生类并实现接口。

### 5. `const` 的使用

面积、周长和名称计算不会修改图形对象，因此成员函数声明为 `const`。遍历时使用 `const Shape*`，可以防止输出过程意外改变图形数据。

## 四、数据安全和异常处理

构造函数在对象创建时验证参数：

- 圆形半径必须大于 0；
- 矩形长和宽必须大于 0；
- 三角形三边必须大于 0，并满足任意两边之和大于第三边。

如果输入不合法，构造函数抛出 `std::invalid_argument`，由 `main` 中的 `try-catch` 统一处理。这样可以避免产生面积为负数、海伦公式开方负数等错误结果。

## 五、踩坑记录

### 1. 忘记写纯虚函数

如果基类函数只是普通虚函数，`Shape` 仍然可以被实例化，无法明确表达“图形基类只提供接口”的设计意图。使用 `= 0` 后，编译器会强制每个具体派生类实现该函数。

### 2. 基类指针调用非虚函数

只有 `virtual` 函数才能实现运行时动态绑定。如果把 `area()` 声明为普通成员函数，通过 `Shape*` 调用时不会根据实际对象类型切换实现。

### 3. 三角形合法性不能只判断边长为正

例如 `1、2、10` 三条边都为正，但无法组成三角形。必须额外检查三角形不等式，否则海伦公式的根号内部可能为负数。

### 4. 圆周率精度

圆的面积和周长需要使用浮点数。代码中使用较高精度的 `π` 常量，并在输出时用 `std::fixed` 和 `std::setprecision(2)` 保留两位小数。保留位数只影响显示，不影响内部计算。

### 5. 基类析构函数不应遗漏 `virtual`

当前示例使用栈对象，不会触发通过基类指针释放对象的问题；但类体系通常会被扩展为动态创建，因此从一开始就声明虚析构函数更稳妥。

### 6. 输入校验与构造校验是两件事

`main` 先检查输入流是否成功读取数字，构造函数再检查数字是否满足几何约束。输入格式错误和参数数值非法属于不同层次的问题，应该分别处理。

## 六、测试思路与示例

可以使用以下输入验证三类图形：

```text
圆形半径：2
矩形长和宽：3 4
三角形三边：3 4 5
```

预期输出（保留两位小数）如下：

```text
Circle
Area: 12.57
Perimeter: 12.57

Rectangle
Area: 12.00
Perimeter: 14.00

Triangle
Area: 6.00
Perimeter: 12.00
```

还应测试半径为 0、矩形宽度为负数、三角形 `1 2 10` 等输入，确认程序能够捕获异常，而不是输出无意义的结果。

## 七、总结

本题通过 `Shape` 抽象基类统一了图形接口，通过继承实现了不同图形的具体算法，通过虚函数和基类指针展示了动态绑定。封装保证了尺寸参数不会被外部随意修改，构造函数校验保证了对象一经创建就处于有效状态。面向接口的设计也便于后续扩展新的图形类型。
