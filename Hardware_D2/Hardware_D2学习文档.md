# Hardware_D2 学习文档

## 一、项目目标

Hardware_D2 的任务是完成直流编码电机的单环位置 PID 控制：

- 0.96 英寸 OLED 通过 IIC 显示当前速度和位置信息；
- 电位器设定目标位置；
- 按钮选择电机的运动速度档位；
- SerialPlot 显示目标位置、实际位置、控制输出和位置误差。

本项目的核心是建立一条完整的闭环控制链路：

```text
电位器设定目标位置
        ↓
目标位置 - 编码器当前位置
        ↓
单环位置 PID
        ↓
按钮选择的输出限幅
        ↓
TB6612 + M310 电机
        ↓
编码器位置反馈
```

电位器的读数直接作为 PID 目标位置。按钮选择 PID/PWM 控制量的最大绝对值，以此形成停止、低速、中速和高速四个档位。

## 二、工程结构

工程按功能分为以下几层：

```text
工程源码
├─ USER
│  ├─ main.c                 初始化、OLED 刷新和串口输出
│  └─ Hardware_D2.uvprojx   Keil 工程文件
├─ HARDWARE
│  ├─ Board.c / Board.h      引脚和 GPIO 初始化
│  ├─ Adc.c / Adc.h          电位器与电源电压采样
│  ├─ Key.c / Key.h          按键扫描和消抖
│  ├─ Encoder.c / Encoder.h  编码器计数
│  ├─ Motor.c / Motor.h      PWM 和方向控制
│  ├─ OLED.c / OLED.h        软件 IIC 显示
│  ├─ PID.c / PID.h          单环位置 PID
│  └─ Control.c / Control.h  100 Hz 闭环控制
├─ SYSTEM                    延时、串口和系统辅助代码
├─ CORE                      Cortex-M3 启动与内核代码
└─ STM32F10x_FWLIB           STM32F1 标准外设库
```

`Control.c` 是各硬件模块与 PID 算法的连接点。TIM2 每 10 ms 调用一次控制过程，`main.c` 读取控制状态并完成显示。

## 三、硬件信号

| 功能 | STM32 引脚 | 外设资源 |
| --- | --- | --- |
| 电位器目标位置 | PA0 | ADC1_CH0 |
| 速度档位按钮 | PA2 | GPIO 输入，上拉 |
| TB6612 PWMA | PB1 | TIM3_CH4 |
| TB6612 AIN1 | PB14 | GPIO 输出 |
| TB6612 AIN2 | PB15 | GPIO 输出 |
| 编码器 E1A | PB6 | TIM4_CH1 |
| 编码器 E1B | PB7 | TIM4_CH2 |
| 驱动板电压采样 | PA6 | ADC1_CH6 |
| OLED SCL | PB10 | 软件 IIC |
| OLED SDA | PB11 | 软件 IIC |
| 串口发送 | PA9 | USART1_TX |
| 串口接收 | PA10 | USART1_RX |

TB6612 使用 A 通道驱动一台 M310 电机。PID 输出的符号决定 AIN1、AIN2 的方向组合，绝对值决定 PWMA 的占空比。

## 四、目标位置设定

PA0 读取 B10K 电位器的中间抽头。ADC 的 12 位转换结果为 `0~4095`，程序将其映射为 `-5000~+5000 count`：

```c
target = -5000 + adc_value * 10000 / 4095;
```

因此：

| ADC 读数 | 目标位置 |
| ---: | ---: |
| 0 | -5000 count |
| 约 2048 | 约 0 count |
| 4095 | +5000 count |

ADC 连续采样 4 次并取平均值，使目标位置随电位器平稳变化。

## 五、编码器位置和速度

PB6、PB7 对应 TIM4 的两个输入通道。TIM4 工作在正交编码器模式，计数方向由 A、B 两相信号的相位关系决定。

控制程序每 10 ms 读取一次 TIM4 计数值并清零：

```text
本周期编码器增量 = TIM4 当前计数值
当前位置 = 当前位置 + 本周期编码器增量
```

位置采用持续累加的 `count` 表示。速度每 20 ms 统计一次：

```text
速度 = 20 ms 内编码器增量 × 50
```

速度单位为 `count/s`。位置反馈参与 PID 运算，速度用于 OLED 显示和运行状态观察。

## 六、单环位置 PID

### 1. 控制误差

位置环误差为：

```text
e(k) = Target(k) - Actual(k)
```

误差为正时，电机向正方向运动；误差为负时，电机向反方向运动。

### 2. 离散 PID

程序使用位置式 PID：

```text
P(k) = Kp × e(k)
I(k) = Ki × Σe(k)
D(k) = Kd × [e(k) - e(k-1)]

u(k) = P(k) + I(k) + D(k)
```

三项的作用分别是：

- 比例项根据当前位置误差产生主要控制作用；
- 积分项累计历史误差，修正稳态位置偏差；
- 微分项反映误差变化速度，为运动过程增加阻尼。

当前参数采用 1000 倍定点数：

```c
#define PID_KP    250L   /* Kp = 0.250 */
#define PID_KI      1L   /* Ki = 0.001 */
#define PID_KD     80L   /* Kd = 0.080 */
#define PID_SCALE 1000L
```

STM32 实际计算过程为：

```c
output = (PID_KP * error
        + PID_KI * integral
        + PID_KD * derivative) / PID_SCALE;
```

### 3. PID 的边界处理

程序对控制变量设置了明确的工作范围：

| 项目 | 数值 | 作用 |
| --- | ---: | --- |
| 误差范围 | ±100000 | 限定 PID 输入范围 |
| 积分范围 | ±200000 | 限定积分累计范围 |
| PID 输出范围 | ±999 | 对应 TIM3 PWM 周期 |
| 位置死区 | ±5 count | 目标附近输出为 0 |

当位置进入 `±5 count` 死区时，控制器将积分清零并停止输出，此时当前位置视为已经到达目标。

## 七、按钮控制速度档位

PA2 使用内部上拉输入，按钮按下时读到低电平。按键接口沿用 D1 的 `Key_Read(mode)`、`KEY1_PRESS` 和 `KEY_UNPRESS` 命名；函数每 10 ms 执行一次，通过连续稳定采样识别一次按下事件。

每次按下按钮，输出上限按以下顺序循环：

```text
0 → 200 → 400 → 700 → 0
```

| 档位 | PID/PWM 输出范围 | 运行状态 |
| --- | --- | --- |
| 停止 | 0 | 电机停止 |
| 低速 | -200~+200 | 低速定位 |
| 中速 | -400~+400 | 中速定位 |
| 高速 | -700~+700 | 高速定位 |

PID 先根据位置误差计算带符号输出，随后由当前档位进行对称限幅：

```c
if (output > limit)  output = limit;
if (output < -limit) output = -limit;
```

这套控制方式保持目标位置不变，通过控制量限幅改变电机到达目标位置的速度。

## 八、PWM 与电机方向

TIM3_CH4 在 PB1 输出约 1 kHz PWM：

```text
TIM3 时钟 = 72 MHz
预分频后计数频率 = 72 MHz / 72 = 1 MHz
PWM 频率 = 1 MHz / 1000 = 1 kHz
```

电机控制逻辑为：

| PID 输出 | AIN1 | AIN2 | PWM 比较值 |
| --- | --- | --- | --- |
| 大于 0 | 1 | 0 | 输出绝对值 |
| 小于 0 | 0 | 1 | 输出绝对值 |
| 等于 0 | 0 | 0 | 0 |

同一个 PID 输出同时包含方向和力度信息，适合位置闭环自动完成正反向定位。

## 九、定时控制与显示调度

系统采用三个不同的时间尺度：

| 任务 | 周期 | 频率 |
| --- | ---: | ---: |
| 编码器读取、ADC 采样、按钮扫描、PID 运算 | 10 ms | 100 Hz |
| 串口数据输出、速度计算 | 20 ms | 50 Hz |
| OLED 刷新 | 100 ms | 10 Hz |

TIM2 中断执行实时控制，主循环执行串口发送和 OLED 刷新。控制中断每次采用相同采样周期，因此 PID 参数与实际时间尺度保持一致。

## 十、OLED 状态显示

SSD1306 OLED 通过 PB10、PB11 软件 IIC 通信，显示四项运行数据：

```text
SPD:+5880     当前速度，count/s
POS:+1250     当前累计位置，count
LIM:+400      当前 PID/PWM 输出上限
TPOS:+3000    电位器目标位置，count
```

OLED 用于观察当前状态，10 Hz 刷新频率与人眼读取速度相匹配。

## 十一、SerialPlot 曲线

USART1 使用 `115200 baud、8N1`，每 20 ms 输出一行纯数字 CSV：

```text
3000,2840,200,160
```

四列数据依次为：

| 列名 | 程序变量 | 含义 |
| --- | --- | --- |
| Target | `pid_target_position` | PID 目标位置 |
| Actual | `position` | 编码器实际位置 |
| Out | `pid_output` | 带符号 PWM 输出 |
| Difout | `pid_error` | 目标位置与实际位置之差 |

一次典型定位过程可以分为三个阶段：

1. 目标改变后，`Difout` 迅速增大，`Out` 达到当前档位的限幅值。
2. 电机接近目标后，`Difout` 减小，PID 输出随之下降。
3. `Actual` 到达 `Target` 附近，`Difout` 接近 0，电机停止。

不同速度档位下，`Target` 相同，`Out` 的最大值分别为 200、400 和 700。通过比较 `Actual` 曲线的上升时间、超调量和稳定时间，可以观察输出限幅对控制质量的影响。

## 十二、PID 参数整定

本项目可按以下顺序理解和调整参数：

1. 令 `Ki=0、Kd=0`，调整 `Kp`，观察位置响应速度和振荡趋势。
2. 加入少量 `Kd`，观察目标附近的超调和振荡变化。
3. 加入少量 `Ki`，观察稳态位置误差的变化。
4. 分别使用 200、400、700 三个输出上限，对比同一目标位置下的响应。

曲线评价指标包括：

- 上升时间：实际位置开始运动到接近目标位置所需的时间；
- 超调量：实际位置越过目标位置的最大距离；
- 调节时间：实际位置进入目标附近并保持稳定所需的时间；
- 稳态误差：系统稳定后目标位置与实际位置的差值。

当前参数体现了速度与稳定性的折中：比例项提供位置响应，微分项改善到位过程，积分项修正较小的长期偏差。

## 十三、学习总结

Hardware_D2 将 ADC、编码器、PWM、按钮、OLED 和串口组合成了一个完整的单环位置闭环系统。

通过本项目，我理解了位置控制中的几个核心关系：

- 电位器给出目标位置；
- 编码器给出实际位置；
- 两者之差形成位置误差；
- PID 把位置误差转换为带方向的 PWM 控制量；
- 按钮通过输出限幅设置运动速度档位；
- OLED 显示状态，SerialPlot 展示动态过程。

从开环 PWM 调速到闭环位置控制，控制目标从“输出多大占空比”转变为“电机到达哪个位置”。执行器的运动结果重新反馈给控制器，形成了可以测量、分析和整定的闭环系统。
