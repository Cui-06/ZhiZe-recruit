# Hardware_D2 实操接线说明

## 1. STM32 引脚分配

| 模块信号 | STM32 引脚 | 说明 |
| --- | --- | --- |
| 目标位置电位器 | PA0 / ADC1_CH0 | 中间抽头，输入范围 0~3.3 V |
| 目标速度按钮 | PA2 | 低电平按下，内部上拉 |
| TB6612 PWMA | PB1 / TIM3_CH4 | A 通道硬件 PWM |
| TB6612 AIN1 | PB14 | A 通道方向输入 1 |
| TB6612 AIN2 | PB15 | A 通道方向输入 2 |
| M310 编码器 E1A | PB6 / TIM4_CH1 | 编码器 A 相 |
| M310 编码器 E1B | PB7 / TIM4_CH2 | 编码器 B 相 |
| 电源 ADC | PA6 / ADC1_CH6 | D153C ADC 分压输出，继续保留 |
| OLED SCL | PB10 | 0.96 英寸 OLED 软件 IIC 时钟 |
| OLED SDA | PB11 | 0.96 英寸 OLED 软件 IIC 数据 |
| USART1 TX | PA9 | 连接 USB-TTL RX |
| USART1 RX | PA10 | 连接 USB-TTL TX |


## 2. D153C 与 TB6612 接线

| D153C 信号 | 连接到 | 说明 |
| --- | --- | --- |
| PWMA | STM32 PB1 | A 通道 PWM |
| AIN1 | STM32 PB14 | 正转时为高电平 |
| AIN2 | STM32 PB15 | 正转时为低电平 |
| STBY | D153C 3.3 V 或 5 V | 必须保持高电平，不能悬空 |
| AO1 | M310 电机动力线 1 | 只接电机绕组线 |
| AO2 | M310 电机动力线 2 | 只接电机绕组线 |

TB6612 A 通道正转控制逻辑：

```text
STBY = 1
AIN1 = 1
AIN2 = 0
PWMA = PWM
```

## 3. 电源接线

```text
外部电源正极 -> D153C VIN/电机电源输入正极
外部电源负极 -> D153C 电机电源输入负极 GND
电脑 USB     -> STM32 核心板 USB 供电接口
STM32 GND    -> D153C GND
```

外部电源只给 D153C 和电机供电，电脑 USB 只给 STM32 供电。电机不能由 STM32 的 3.3 V 或电脑 USB 直接供电。

STM32、D153C、M310 编码器和 USB-TTL 必须有共同参考地。不要同时把 D153C 的 5 V 输出、USB-TTL 的 5 V 和 STM32 USB 5 V 接在一起，避免电源互相反灌。

## 4. M310 六线连接

```text
M310 动力线 1  -> D153C AO1
M310 动力线 2  -> D153C AO2
M310 编码器 E1A -> STM32 PB6
M310 编码器 E1B -> STM32 PB7
M310 编码器 VCC -> 3.3 V
M310 编码器 GND -> 公共 GND
```

## 5. OLED 显示

本工程使用 0.96 英寸 SSD1306 OLED，通过软件 IIC 显示电机当前速度和累计位置。

```text
OLED SCL -> STM32 PB10
OLED SDA -> STM32 PB11
OLED VCC -> STM32 3.3 V
OLED GND -> STM32 GND
```

屏幕显示实际值和目标值：

```text
SPD:+5880
POS:-12345
LIM:+400
TPOS:+12000
```

`SPD/POS` 为当前速度和位置，`LIM` 为按钮选择的 PID/PWM 输出上限，`TPOS` 为电位器目标位置。速度和位置单位分别为 `count/s` 和 `count`。

## 6. 电源采样与串口

### 目标位置电位器

```text
电位器一侧端子 -> STM32 3.3 V
电位器另一侧端子 -> STM32 GND
电位器中间抽头 -> STM32 PA0 / ADC1_CH0
```

电位器只能接 3.3 V，不能接 5 V。程序将 ADC 的 `0~4095` 映射为 `-5000~+5000 count` 的目标位置。

### USB-TTL 串口

串口参数：`115200 baud、8 数据位、1 停止位、无校验`。

```text
USB-TTL TX  -> STM32 PA10 / USART1_RX
USB-TTL RX  -> STM32 PA9  / USART1_TX
USB-TTL GND -> STM32 GND
```


串口以约 50 Hz 输出四列 CSV 数据：

```text
5000,4870,230,130
```

四列依次为 `Target`、`Actual`、`Out`、`Difout`：第 1 列是 PID 内部目标位置，第 2 列是编码器当前位置，第 3 列是 PID 带符号 PWM 输出，第 4 列是位置误差。

## 7. PID 控制与运行方式

原来的 K2/K3 方向按键和开环调速已经删除，仅保留一个目标速度按钮。电机方向由单环位置 PID 输出的正负号自动决定。

旋转 PA0 电位器即可改变目标位置：

- 电位器中点对应约 `0 count`；
- 向一侧旋转，目标位置向正方向移动；
- 向另一侧旋转，目标位置向负方向移动；
- 按钮依次选择停止、低速、中速和高速，对应 PID/PWM 输出上限 `0`、`200`、`400`、`700`。

速度按钮接线：

```text
STM32 PA2 ---- 速度按钮 ---- GND
```

控制器每 10 ms 运行一次，电位器目标位置直接送入单环位置 PID，编码器反馈用于计算当前位置和位置误差。按钮通过限制 PID 带符号 PWM 的最大绝对值控制运动速度；输出上限为 `0` 时电机停止。
