# Hardware_A1 Multisim 仪表放大器仿真学习文档

## 1. 题目目标

本题要求使用 Multisim 搭建仪表放大器仿真电路，并用示波器观察输出端信号。仪表放大器正常工作的标志是：输入方波经过电路后，输出端仍为方波，并且输出幅值相对输入发生放大。

本题交付物包括：

```text
Hardware_A1.ms14
01_仿真截图.png
02_示波器截图.png
README.md
```

## 2. 使用元器件

本次仿真使用的主要元器件如下：

```text
741 运算放大器：3 个
电阻：若干
CLOCK_VOLTAGE 方波电压源：1 个
VCC / VEE 双电源：+15V / -15V
GROUND：公共地
OSCILLOSCOPE：示波器
```

其中 741 运放的关键引脚为：

```text
2 脚：反相输入端 -
3 脚：同相输入端 +
4 脚：负电源 VEE，接 -15V
6 脚：输出端
7 脚：正电源 VCC，接 +15V
```

## 3. 电路搭建过程

本次采用三运放仪表放大器结构。左侧两个 741 作为输入级，右侧一个 741 作为差分输出级。

输入连接方式：

```text
方波源 V1+ 接上方输入运放 U1 的 3 脚
方波源 V1- 接 GND
下方输入运放 U2 的 3 脚接 GND
```

前级反馈连接方式：

```text
U1 的 6 脚通过反馈电阻接回 U1 的 2 脚
U2 的 6 脚通过反馈电阻接回 U2 的 2 脚
U1 的 2 脚和 U2 的 2 脚之间接增益电阻 Rg
```

后级差分放大连接方式：

```text
U1 输出端接入 U3 的一路输入网络
U2 输出端接入 U3 的另一路输入网络
U3 的 6 脚作为最终输出端 Vout
U3 的 6 脚接示波器 B+
示波器 B- 接 GND
```

运放供电方式：

```text
U1、U2、U3 的 7 脚均接 +15V
U1、U2、U3 的 4 脚均接 -15V
```

## 4. 仿真参数

方波源参数设置为：

```text
频率：1kHz
幅值：100mV
偏置：0V
```

示波器设置：

```text
时间轴：2ms/Div
通道 A：100mV/Div，用于观察输入方波
通道 B：100mV/Div，用于观察输出方波
耦合方式：直流
```

## 5. 仿真结果

示波器截图中可以观察到：

```text
通道 A 输入幅值约为 100mV
通道 B 输出幅值约为 202mV
```

因此实际放大倍数约为：

```text
Av ≈ 202mV / 100mV ≈ 2.02
```

该结果与理论放大倍数约为 2 的计算结果基本一致，说明仪表放大器仿真电路能够正常工作。

## 6. 关键知识点

### 6.1 仪表放大器的作用

仪表放大器主要用于放大两个输入端之间的微小差分电压，同时尽量抑制两个输入端共同存在的共模干扰。

### 6.2 双电源供电

741 运算放大器通常需要双电源供电。本次使用：

```text
VCC = +15V
VEE = -15V
GND = 0V
```

如果正负电源接反，运放无法正常工作，输出波形会异常。

### 6.3 示波器参考端

Multisim 示波器的每个通道都有正端和负端。测量输出时不能只接 `B+`，还需要将 `B-` 接到 `GND`，否则通道没有明确参考电位，波形可能显示错误。

## 7. 踩坑记录

### 7.1 把直流源当成方波源

最开始参考图中使用了 `2V` 和 `4V` 直流输入，但题目要求输出端标志是方波。因此需要改用 `CLOCK_VOLTAGE` 或类似方波信号源作为输入。

### 7.2 示波器未接参考地

示波器只接正端时，波形不稳定或无法正确显示。修正为：

```text
A+ 接输入信号，A- 接 GND
B+ 接输出信号，B- 接 GND
```

### 7.3 输出端误认为接地

右侧 741 的 6 脚是输出端，不能直接接地。输出端可以通过负载电阻接地，也可以接示波器观察，但不能被导线短接到 GND。

## 8. 总结

通过本次仿真，我掌握了三运放仪表放大器的基本结构、741 运放的供电和引脚连接方式、方波源的使用方法，以及 Multisim 示波器的基本接法。最终仿真结果显示输入为 `100mV` 方波时，输出约为 `202mV` 方波，证明电路实现了约 2 倍放大。
