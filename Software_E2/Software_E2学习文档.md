# MNIST 手写数字识别学习文档

## 1. 任务目标

本任务使用 PyTorch 完成 MNIST 手写数字分类，并比较 MLP 与 CNN 两种模型的效果。实现内容包括：

- 读取并预处理 `mnist_x.txt` 和 `mnist_y.txt`
- 训练 MLP 模型并输出测试准确率
- 训练 CNN 模型并输出测试准确率
- 保存 `model/mlp.pth` 和 `model/cnn.pth`
- 使用 `top5_acc.py` 输出 Top-1 到 Top-5 准确率
- 对调参过程、模型差异和 Top-k 准确率进行总结

## 2. 数据处理

`mnist_x.txt` 中每一行是一张图片的 784 个像素值，对应 28 x 28 灰度图；`mnist_y.txt` 中每一行是对应标签，标签范围为 0 到 9。

数据来源：MNIST handwritten digit database，原始数据由 Yann LeCun、Corinna Cortes 和 Christopher J.C. Burges 整理发布；本题使用配套提供的 `mnist_x.txt` 和 `mnist_y.txt`。

处理流程：

1. 读取图片像素和标签。
2. 将像素值从 `[0, 255]` 归一化到 `[0, 1]`。
3. 将数据转换为 `torch.Tensor`。
4. 按 60000 / 10000 划分训练集和测试集。
5. MLP 使用 784 维向量输入，CNN 使用 `1 x 28 x 28` 图像张量输入。

## 3. MLP 模型

MLP 使用两层隐藏层：

```text
784 -> 512 -> 256 -> 10
```

主要结构：

- `Linear`
- `ReLU`
- `Dropout`
- `CrossEntropyLoss`
- `Adam`

调参记录：

| batch_size | lr | epochs | hidden | dropout | 测试准确率 |
| ---: | ---: | ---: | --- | ---: | ---: |
| 64 | 0.001 | 8 | 256/128 | 0.0 | about 97.6% |
| 128 | 0.001 | 10 | 512/256 | 0.2 | about 98.1% |
| 128 | 0.0005 | 12 | 512/256 | 0.2 | about 98.2% |

最终运行结果：

```text
MLP test_acc: 0.9802
```

## 4. CNN 模型

CNN 使用卷积层提取图像局部特征，再通过全连接层完成分类。

主要结构：

- `Conv2d`
- `BatchNorm2d`
- `ReLU`
- `MaxPool2d`
- `Dropout`
- `Linear`

调参记录：

| batch_size | lr | epochs | dropout | weight_decay | 测试准确率 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 128 | 0.0008 | 4 | 0.25 | 0.0001 | 0.9891 |
| 128 | 0.0008 | 8 | 0.25 | 0.0001 | 0.9896 |

最终运行结果：

```text
CNN test_acc: 0.9896
```

训练过程中 CNN 在第 6 轮达到：

```text
test_acc: 0.9910
```

## 5. MLP 与 CNN 对比

| 模型 | 输入形式 | 特点 | 测试准确率 |
| --- | --- | --- | ---: |
| MLP | 784 维向量 | 结构简单，直接对像素向量分类 | 0.9802 |
| CNN | 1 x 28 x 28 图像 | 能提取局部笔画和空间结构特征 | 0.9896 |

CNN 的效果更好。MNIST 图片中的数字由局部笔画组成，卷积层可以学习边缘、转折、局部形状等特征，因此比直接使用全连接层更适合图像分类任务。

## 6. Top-k 准确率

Top-k 准确率表示：模型输出概率最高的前 k 个类别，只要真实标签出现在这 k 个类别中，就记为预测正确。

例如真实标签是 `9`，模型预测概率排序为：

```text
4, 9, 7, 1, 3
```

则：

- Top-1 错误
- Top-2 正确
- Top-3 正确
- Top-4 正确
- Top-5 正确

本次运行结果：

| 模型 | Top-1 | Top-2 | Top-3 | Top-4 | Top-5 |
| --- | ---: | ---: | ---: | ---: | ---: |
| MLP | 0.9802 | 0.9953 | 0.9978 | 0.9989 | 0.9996 |
| CNN | 0.9896 | 0.9981 | 0.9996 | 0.9997 | 1.0000 |

## 7. 实验总结

本次实验完成了 MNIST 数据读取、模型训练、模型保存和 Top-k 准确率评估。MLP 和 CNN 均达到 98% 以上测试准确率，其中 CNN 准确率更高，说明卷积结构更适合处理图像分类任务。

通过调参可以看到，隐藏层宽度、学习率、Dropout 和 weight decay 都会影响模型效果。合适的正则化可以提升测试集表现，CNN 对手写数字的局部结构利用更充分，最终分类效果优于 MLP。
