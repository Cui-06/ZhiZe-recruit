## 3. 棋盘环境设计

井字棋棋盘共有 9 个位置，使用长度为 9 的数组表示：

```python
State = np.zeros(9).astype(np.int8)
```

棋盘中每个位置有 3 种状态：

| 数值 | 含义 |
| --- | --- |
| `0` | 空位 |
| `1` | Agent1 的棋子，显示为 O |
| `2` | Agent2 的棋子，显示为 X |

这种表示方式简单直接，也方便作为状态价值表的索引。

## 4. 合法落子判断

合法落子位置就是棋盘中值为 `0` 的位置：

```python
available = np.where(Outcome == 0)[0]
```

智能体只能从 `available` 中选择位置落子，因此不会出现覆盖已有棋子的情况。

## 5. 胜负判断

胜负判断函数为 `Judge(Outcome, OOXX_Index)`。

判断内容包括：

- 三行是否连成一线。
- 三列是否连成一线。
- 两条对角线是否连成一线。
- 棋盘是否已满，若满且无人获胜，则为平局。

返回值含义：

| 返回值 | 含义 |
| --- | --- |
| `0` | 胜负未分 |
| `1` | Agent1 获胜 |
| `2` | Agent2 获胜 |
| `3` | 平局 |

## 6. 强化学习设计

### 6.1 状态价值表

井字棋有 9 个位置，每个位置 3 种状态，因此总状态数最多为：

```text
3^9 = 19683
```

代码中使用 9 维数组存储状态价值：

```python
self.value = np.zeros((3, 3, 3, 3, 3, 3, 3, 3, 3))
```

智能体会根据训练过程不断更新这个价值表。

### 6.2 ε-Greedy 策略

智能体选择动作时使用 `epsilon-greedy`：

- 以 `epsilon` 的概率随机探索。
- 以 `1 - epsilon` 的概率选择当前价值最高的落子位置。

训练前期保留随机性，让智能体探索更多局面；训练后期将 `epsilon` 设为 0，让智能体使用已经学到的策略。

### 6.3 TD 更新

代码中使用类似时序差分的方法更新状态价值：

```python
Error = value[next_state] - value[last_state]
value[last_state] += alpha * Error
```

当某一方获胜时，最终状态价值设为：

```python
胜利方最终状态价值 = 1
失败方上一状态价值 = -1
```

这样智能体会逐渐倾向于选择能通向胜利状态的动作。

## 7. 训练过程

训练过程为两个 Agent 自我对弈：

```text
初始化空棋盘
Agent1 落子
判断 Agent1 是否获胜
若未结束，Agent2 落子
判断 Agent2 是否获胜
重复直到胜负或平局
记录本局结果
```

本次训练参数：

| 参数 | 数值 |
| --- | --- |
| 训练局数 | `30000` |
| 探索停止局数 | `20000` |
| 初始 epsilon | `0.1` |
| 学习率 alpha | `0.1` |

## 10. 总结

通过本题，我理解了强化学习中状态、动作、价值、策略和奖励之间的关系。井字棋状态空间较小，因此可以直接使用表格记录状态价值。智能体通过自我对弈不断更新价值表，最终学到较稳定的策略。

本题没有使用现成强化学习库，而是手动实现了状态表示、合法动作、胜负判断、ε-Greedy 策略、TD 更新和训练曲线统计，更有助于理解强化学习的基本流程。
