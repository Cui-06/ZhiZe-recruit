# Hardware_D1 实操接线说明

## 1. STM32 引脚分配

| 模块信号 | STM32 引脚 | 说明 |
| --- | --- | --- |
| Key1 | PA2 | 低电平按下，内部上拉 |
| Key2 | PA3 | 低电平按下，内部上拉 |
| Key3 | PA4 | 低电平按下，内部上拉 |
| TB6612 PWMA | PB1 / TIM3_CH4 | A 通道硬件 PWM |
| TB6612 AIN1 | PB14 | A 通道方向输入 1 |
| TB6612 AIN2 | PB15 | A 通道方向输入 2 |
| M310 编码器 E1A | PB6 / TIM4_CH1 | 编码器 A 相 |
| M310 编码器 E1B | PB7 / TIM4_CH2 | 编码器 B 相 |
| 电源 ADC | PA6 / ADC1_CH6 | D153C ADC 分压输出 |
| USART1 TX | PA9 | 连接 USB-TTL RX |
| USART1 RX | PA10 | 连接 USB-TTL TX |

## 2. D153C 与 TB6612 接线

| D153C 信号 | 连接到 | 说明 |
| --- | --- | --- |
| PWMA | STM32 PB1 | A 通道 PWM |
| AIN1 | STM32 PB14 | 正转时为高电平 |
| AIN2 | STM32 PB15 | 正转时为低电平 |
| STBY | D153C 3.3 V 或 5 V | 必须保持高电平，不能悬空 |
| AO1 | M310 电机动力线 1 | 只接电机绕组线 |
| AO2 | M310 电机动力线 2 | 只接电机绕组线 |

TB6612 A 通道正转控制逻辑：

```text
STBY = 1
AIN1 = 1
AIN2 = 0
PWMA = PWM
```

## 3. 电源接线

```text
外部电源正极 -> D153C VIN/电机电源输入正极
外部电源负极 -> D153C 电机电源输入负极 GND
电脑 USB     -> STM32 核心板 USB 供电接口
STM32 GND    -> D153C GND
```

外部电源只给 D153C 和电机供电，电脑 USB 只给 STM32 供电。电机不能由 STM32 的 3.3 V 或电脑 USB 直接供电。

## 4. M310 六线连接

```text
M310 动力线 1  -> D153C AO1
M310 动力线 2  -> D153C AO2
M310 编码器 E1A -> STM32 PB6
M310 编码器 E1B -> STM32 PB7
M310 编码器 VCC -> 3.3 V
M310 编码器 GND -> 公共 GND
```

## 5. 电源采样与串口

### 电源采样

```text
D153C ADC 分压输出 -> STM32 PA6 / ADC1_CH6
```

D153C 原理图使用约 `1/11` 分压，不能把电机电源 `VIN` 原电压直接接到 PA6。PA6 输入电压必须不超过 3.3 V，ADC 地接公共 GND。

### USB-TTL 串口

串口参数：`115200 baud、8 数据位、1 停止位、无校验`。

```text
USB-TTL TX  -> STM32 PA10 / USART1_RX
USB-TTL RX  -> STM32 PA9  / USART1_TX
USB-TTL GND -> STM32 GND
```

串口输出示例：

```text
Motor A Pos=120 Speed=300 count/s
```

## 6. 按键与运行状态

| 按键 | 功能 |
| --- | --- |
| Key1 | 第一次低速、第二次中速、第三次高速、第四次停止 |
| Key2 | 设置电机正转 |
| Key3 | 设置电机反转 |

按键接线方式：

```text
PA2/PA3/PA4 ---- 按钮 ---- GND
```

程序使用内部上拉，不需要外接上拉电阻。上电后电机初始停止；按下 Key1 后按速度档位循环运行。

接线和改线前应关闭 D153C 外部电源。外部电机电源电压应符合 D153C 与 M310 的额定范围，电机动力线不得接到编码器信号接口。
