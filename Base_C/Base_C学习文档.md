# Base_C 学习文档：Linux 的使用

## 1. 学习目标

本题要求学习 Linux 的基本使用方法，能够完成 Linux 环境配置、基础 Shell 指令操作、文件查找与文本处理、分区与硬盘查看、压缩打包、权限与用户管理、进程与资源查看、远程连接与文件传输，以及环境变量和软件环境的基本管理。


## 2. Linux 环境配置

题目要求中首先提到要配置 Linux 环境，常见方式包括：

1. 安装 WSL。
2. 使用虚拟机。
3. 安装双系统。

对于 Windows 用户来说，WSL 是最方便的入门方式之一，适合快速进入 Linux 命令行环境；虚拟机适合完整体验独立 Linux 系统；双系统则更接近真实 Linux 使用场景。

Linux 环境配置完成后，通常还需要补充以下内容：

- 配置软件源。
- 安装常用开发工具。
- 配置终端和 Shell。
- 安装代码编辑器或远程开发插件。

## 3. 基础 Shell 指令

Shell 是 Linux 中最常用的交互方式。学习 Linux 时，先掌握基础命令非常重要。

### 3.1 文件与目录查看

常用命令：

```bash
pwd
ls
ls -l
ls -a
```

含义总结：

| 命令 | 作用 |
| --- | --- |
| `pwd` | 显示当前所在目录 |
| `ls` | 列出目录内容 |
| `ls -l` | 以详细格式显示文件信息 |
| `ls -a` | 显示隐藏文件 |

### 3.2 目录切换与创建

```bash
cd 目录名
mkdir 目录名
mkdir -p a/b/c
```

学习中要理解的点：

- `cd` 用于切换目录。
- `mkdir` 用于创建目录。
- `-p` 可以一次性创建多级目录。

### 3.3 文件操作

```bash
touch 文件名
cp 源文件 目标文件
mv 源文件 目标文件
rm 文件名
cat 文件名
```

这些命令分别用于创建文件、复制、移动、删除和查看文件内容。

### 3.4 帮助命令

```bash
man 命令
命令 --help
```

Linux 命令很多，记忆重点不是背所有参数，而是学会查帮助文档、查手册和查例子。

## 4. 文件查找与文本处理

这是 Linux 使用中非常实用的一部分，尤其适合在项目和日志里快速定位信息。

### 4.1 文件查找

常用命令：

```bash
find
locate
which
whereis
```

它们的用途不同：

| 命令 | 作用 |
| --- | --- |
| `find` | 按条件搜索文件，功能最强 |
| `locate` | 通过索引快速查找文件 |
| `which` | 查找命令所在路径 |
| `whereis` | 查找命令、源码和手册位置 |

### 4.2 文本查看与搜索

```bash
grep 关键词 文件名
sed
awk
head
tail
```

这些工具常用于筛选日志、提取字段和查看大文件。

常见理解：

- `grep` 用于按关键词过滤内容。
- `head` 查看前几行。
- `tail` 查看后几行。
- `sed` 适合文本替换和流式处理。
- `awk` 适合按列处理文本。

### 4.3 组合使用

Linux 命令的强大之处在于可以通过管道组合：

```bash
cat log.txt | grep error
```

这类用法适合从日志中快速找出关键信息。

## 5. 分区与硬盘查看

Linux 中了解磁盘和分区情况，有助于管理系统空间和存储位置。

常用命令：

```bash
df -h
du -sh 文件夹
lsblk
fdisk -l
```

含义总结：

| 命令 | 作用 |
| --- | --- |
| `df -h` | 查看磁盘整体使用情况 |
| `du -sh` | 查看目录占用空间 |
| `lsblk` | 查看块设备和分区 |
| `fdisk -l` | 查看磁盘分区信息 |

学习这部分时重点是理解：

- 磁盘和分区的区别。
- 挂载点的概念。
- 系统空间不足时如何定位占用大的目录。

## 6. 压缩与打包

Linux 下常见的压缩和打包命令包括：

```bash
tar
zip
unzip
gzip
gunzip
```

常见示例：

```bash
tar -czvf archive.tar.gz folder/
tar -xzvf archive.tar.gz
zip -r archive.zip folder/
unzip archive.zip
```

这些命令常用于：

- 打包提交材料。
- 传输项目文件。
- 备份目录。

## 7. 权限与用户管理

Linux 的权限管理是非常重要的基础内容。文件和目录通常都有三类权限主体：

- 所有者。
- 所属组。
- 其他用户。

常见命令：

```bash
chmod
chown
sudo
su
id
whoami
```

### 7.1 权限查看

使用 `ls -l` 可以看到文件权限，例如：

```text
-rwxr-xr--
```

其中：

- `r` 表示读权限。
- `w` 表示写权限。
- `x` 表示执行权限。

### 7.2 权限修改

```bash
chmod 755 文件名
chmod u+x 文件名
```

### 7.3 用户相关

```bash
whoami
id
sudo 命令
```

学习这部分的重点是理解权限控制的原因，以及为什么某些系统命令必须使用 `sudo` 才能执行。

## 8. 进程与资源查看

Linux 里可以通过命令查看系统运行状态和资源使用情况。

常用命令：

```bash
ps
top
htop
free -h
kill
killall
```

### 8.1 进程查看

- `ps` 查看当前进程。
- `top` 实时查看进程和资源占用。
- `htop` 是更友好的交互式进程查看工具。

### 8.2 内存与负载

```bash
free -h
```

可以查看内存、缓存和交换分区使用情况。

### 8.3 结束进程

```bash
kill 进程号
killall 进程名
```

学习这部分的重点是知道如何判断某个程序是否占用过多资源，以及如何终止异常进程。

## 9. 远程连接与远程传输

题目要求中还包括远程连接与远程文件传输。常见方式有：

```bash
ssh
scp
sftp
rsync
```

### 9.1 SSH 远程登录

```bash
ssh 用户名@主机地址
```

SSH 常用于远程登录服务器，也常用于远程开发。

### 9.2 文件传输

```bash
scp 本地文件 用户名@主机地址:目标路径
```

或者使用 `sftp`、`rsync` 做文件同步和传输。

### 9.3 VSCode 远程开发

VSCode 的 Remote SSH 功能可以直接连接远程 Linux 主机，在本地界面中编辑远程文件。这个方式非常适合开发和调试，也符合题目要求中的远程写代码场景。

## 10. 环境变量与软件环境

Linux 中的软件运行很依赖环境变量和系统路径设置。

常见命令：

```bash
echo $PATH
export
source
env
```

### 10.1 环境变量

环境变量会影响系统查找命令和软件运行行为。例如 `PATH` 决定了终端能直接执行哪些命令。

### 10.2 临时设置与永久设置

```bash
export MYVAR=123
```

临时设置只对当前终端有效。如果要永久生效，通常需要写入 `~/.bashrc`、`~/.zshrc` 或系统配置文件，然后执行：

```bash
source ~/.bashrc
```

### 10.3 软件环境

软件环境管理还包括：

- 安装软件包。
- 配置依赖。
- 使用虚拟环境。
- 管理多个版本的工具链。

## 11. 学习中的关键知识点

根据题目要求，Linux 学习重点可以总结为以下几点：

1. 会搭建 Linux 环境，并知道不同安装方式的特点。
2. 会使用常见 Shell 命令完成日常操作。
3. 会查找文件、筛选日志和处理文本。
4. 会查看磁盘分区和空间占用。
5. 会使用压缩打包命令整理文件。
6. 会理解文件权限和用户权限。
7. 会查看进程、内存和系统资源。
8. 会使用 SSH 和文件传输工具进行远程操作。
9. 会管理环境变量和基础软件环境。
