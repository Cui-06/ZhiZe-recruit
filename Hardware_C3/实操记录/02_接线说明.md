# Hardware_C3 实操接线说明

## 1. 8051 引脚分配

| 模块信号 | 8051 引脚 | 说明 |
| --- | --- | --- |
| 矩阵键盘 8 根线 | P1.0~P1.7 | 矩阵键盘独占 P1 |
| USB-TTL TXD | P3.0 / RXD | PC 向单片机发送数据 |
| USB-TTL RXD | P3.1 / TXD | 单片机向 PC 发送数据 |
| USB-TTL GND | 8051 GND | 串口信号参考地 |
| 电脑 USB | 8051 开发板 USB 供电接口 | 单片机实际供电来源 |
| MG310 编码器 A 相 | P3.2 / INT0 | E2A，A 相边沿中断 |
| MG310 编码器 B 相 | P3.3 | E2B，读取方向 |
| OLED SCL | P3.4 | 软件 I2C 时钟 |
| OLED SDA | P3.5 | 软件 I2C 数据 |
| TB6612 PWMA | P2.1 | A 通道 PWM |
| TB6612 AIN1 | P2.6 | A 通道方向输入 1 |
| TB6612 AIN2 | P2.7 | A 通道方向输入 2 |
| 蜂鸣器 | P2.5 | 救援状态提示音 |
| 数码管段选 | P0 | 动态显示段码 |
| 数码管位选 | P2.2~P2.4 | 74HC138 位选 |

## 2. D153C 与 TB6612 接线

当前程序使用 TB6612 A 通道：

| D153C 信号 | 连接到 | 说明 |
| --- | --- | --- |
| PWMA | 8051 P2.1 | PWM 使能 |
| AIN1 | 8051 P2.6 | 正转时为高电平 |
| AIN2 | 8051 P2.7 | 正转时为低电平 |
| STBY | D153C 逻辑 5V 或 3V3 | 必须保持高电平，不能悬空 |
| AO1 | MG310 电机动力线 1 | 只接电机绕组线 |
| AO2 | MG310 电机动力线 2 | 只接电机绕组线 |

## 3. 电源接线

```text
7.4V 外部电源正极 -> D153C VIN/电机电源输入正极
7.4V 外部电源负极 -> D153C 电机电源输入负极 GND2
电脑 USB 接口      -> 8051 开发板 USB 供电接口
8051 VCC           -> OLED VCC
8051 GND           -> OLED GND
D153C 5V/3V3 输出  -> 不接 8051 和 OLED
D153C GND/GND2     -> 不额外连接 8051 GND
```

说明：这是本项目最终实物验证成功的供电方式。外部 7.4V 只进入 D153C，电脑 USB 只给 8051 供电，OLED 跟随 8051 供电。D153C 板载的 5V/3V3 输出未使用，不能再接到由电脑 USB 供电的 8051 VCC。

## 4. MG310 六线连接

```text
MG310 动力线 1 -> D153C AO1
MG310 动力线 2 -> D153C AO2
MG310 编码器 E2A -> 8051 P3.2
MG310 编码器 E2B -> 8051 P3.3
MG310 编码器 VCC -> D153C 5V 或 3V3（按编码器额定电压选择）
MG310 编码器 GND -> D153C 5V/3V3 输出排针的 GND
```

## 5. 串口通信

串口参数：9600 baud、8 数据位、1 停止位、无校验。

PC 连接串口时，TXD/RXD 交叉连接；8051 同时通过电脑 USB 接口取得工作电源。D153C 的 5V/3V3 输出不接 8051。

矩阵键盘：

| 按键 | 功能 |
| --- | --- |
| S1~S9 | 输入数字 1~9 |
| S10 | 输入数字 0 |
| S11 | 选择最后一位并闪烁 |
| S12 | 确认删除最后一位 |
| S16 | 拨号 |

输入 `120` 后按 S16，通信流程为：

```text
单片机 -> PC：需要救援
PC -> 单片机：报告位置
单片机 -> PC：01
PC -> 单片机：收到
```

PC 手动发送中文时使用 UTF-8 HEX：

```text
报告位置：E6 8A A5 E5 91 8A E4 BD 8D E7 BD AE
收到：    E6 94 B6 E5 88 B0
```

## 6. 运行状态

收到严格匹配的“收到”后，电机高速正转、蜂鸣器播放提示音、OLED 滚动显示同时开始；达到设定时间后停止电机、蜂鸣器和 OLED，并清空数码管和号码显示。
