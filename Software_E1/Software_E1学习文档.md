# Software_E1 学习文档：BP 神经网络算法实现

## 1. 题目要求

本题要求手动实现多层感知机 MLP，不使用 PyTorch、TensorFlow 等深度学习框架，可以使用 NumPy 等基础库。目标是训练网络拟合函数，并通过模板中的测试。

本次实现使用 Python 和 NumPy，完成了：

- 一维函数拟合：`y = sin(x)`
- 二维函数拟合：`y = sin(x1) * cos(x2)`
- 手写前向传播
- 手写反向传播
- 手写参数更新

## 2. 网络结构

代码中实现了一个简单的单隐藏层 BP 神经网络：

```text
输入层 -> tanh 隐藏层 -> 输出层
```

一维网络：

```text
1 -> 64 -> 1
```

二维网络：

```text
2 -> 192 -> 1
```

隐藏层使用 `tanh` 激活函数，输出层不使用激活函数，直接输出拟合结果。

## 3. 关键知识点

### 3.1 前向传播

前向传播用于根据当前参数计算预测值：

```python
Z1 = X @ W1 + b1
A1 = np.tanh(Z1)
Y = A1 @ W2 + b2
```

其中 `W1`、`b1` 是输入层到隐藏层的参数，`W2`、`b2` 是隐藏层到输出层的参数。

### 3.2 损失函数

训练时使用均方误差 MSE：

```python
MSE = mean((pred - y) ** 2)
```

预测值越接近真实函数值，损失越小。

### 3.3 反向传播

反向传播根据链式法则计算每个参数对损失的影响。核心是从输出层往前推导梯度：

```python
dY = 2.0 * (pred - yb) / batch_n
dW2 = A1.T @ dY
db2 = np.sum(dY, axis=0, keepdims=True)
dZ1 = (dY @ W2.T) * (1.0 - A1 ** 2)
dW1 = X.T @ dZ1
db1 = np.sum(dZ1, axis=0, keepdims=True)
```

其中 `1 - A1 ** 2` 是 `tanh` 激活函数的导数。

### 3.4 输入归一化

原始输入范围是 `[0, 2π]`。为了让训练更稳定，我将输入归一化到 `[-1, 1]`：

```python
x / math.pi - 1.0
```

归一化后，神经网络更容易训练。

### 3.5 参数更新

代码中使用 Adam 方式更新参数。反向传播梯度仍然是手写的，Adam 只是让训练收敛更快、更稳定。

## 5. 总结

通过本题，我理解了 BP 神经网络的基本流程：先进行前向传播得到预测值，再计算损失函数，然后通过反向传播计算梯度，最后更新参数。相比直接调用深度学习框架，手写 BP 更能理解神经网络参数是如何被训练出来的。
